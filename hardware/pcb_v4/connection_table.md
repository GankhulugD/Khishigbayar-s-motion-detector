# MotionCare v4 (ESP32-S3-Zero): холболтын дэлгэрэнгүй тайлбар

Хоёр самбарыг давхарлаж угсарна. Самбар бүр 36 × 34 мм хэмжээтэй, 2 давхарга зэстэй, нийтдээ 4 давхарга зэс болно.

- Утасны (замын) өргөн: дохионы зам 60 mil (1.52 мм), тэжээлийн зам 80 mil (2.03 мм). Бүх зам 50 mil-ээс өргөн.
- Холболт нь хүснэгттэй 100 % тохирч байгааг программаар шалгасан, зам хоорондын зай 0.3 мм-ээс багагүй (DRC OK).

> **«VBAT», «VSYS» гэдэг нь модулийн хөлийн нэр биш, шугамын нэр юм.**
> - **VBAT** бол батерейн +3.7 V шугам. TP4056-ийн **OUT+** хөлөөс гарна.
> - **VSYS** бол D1 диодын дараах шугам. ESP32-S3-Zero-ийн **5V** хөлөнд орно.

---

## 0. v3-аас юу өөрчлөгдсөн бэ

| | v3 (ESP32-C3 SuperMini) | **v4 (ESP32-S3-Zero)** |
|---|---|---|
| Модулийн хэмжээ | 22.5 × 18 мм, 2 × 8 хөл | **23.5 × 18 мм, 2 × 9 хөл** |
| Модулийн байрлал | A доод тал, USB ↑ | **A доод тал, 180° эргүүлсэн, USB-C ↓** (TP4056-ийн USB-тэй нэг ирмэгт) |
| OLED | Хөл нь доошоо | **Хөл нь дээшээ**, firmware дээр `OLED_ROTATE_180 = 0` болгоно |
| Тэжээл | OUT+ → 5V шууд | **OUT+ → D1 (SS34) → 5V** |
| J4 холбогч | Доод ирмэгт | **Дээд хэсэгт** (y = 5.6 мм) |
| Бэхэлгээний нүх | Зүүн дээд, баруун доод | **Зүүн дээд, баруун дээд** (Ø2.2 мм, M2) |

### Яагаад D1 диод нэмсэн бэ

ESP32-S3-Zero-ийн 5V хөл нь USB-C-ийн 5 V-той шууд холбоотой. Програм хуулахаар USB-C залгахад диодгүй бол 5 V батерей руу буцаж орно. Ингэвэл батерей болон TP4056 эвдэрч, гал гарах эрсдэлтэй.

SS34 Шоттки диод энэ урсгалыг хаадаг. Ингэснээр USB залгаатай үед ч батерей аюулгүй байна.

## 1. Модуль тус бүрийн хөл хаашаа холбогдох вэ

Хөлийн нэрийг модуль дээр бичигдсэн яг тэр нэрээр нь бичлээ.

### ESP32-S3-Zero: 18 хөлөөс 5-ыг ашиглана

Модулийн өөрийн нүүрээс, USB-C-ийг дээш харуулж харахад хөлүүд дараах дарааллаар байна (Waveshare-ийн pinout зураг):

| Зүүн эгнээ (дээрээс доош) | Баруун эгнээ (дээрээс доош) |
|---|---|
| **5V** | TX |
| **GND** | RX |
| **3V3** | GP13 |
| GP1 | GP12 |
| GP2 | GP11 |
| GP3 | GP10 |
| GP4 | GP9 |
| GP5 | GP8 |
| **GP6** | **GP7** |

| S3-Zero хөл | Юу вэ | Хаашаа холбогдох вэ |
|---|---|---|
| **5V** | Тэжээлийн оролт (3.7–6 V) | **D1 катод (K)** → D1 анод → TP4056 **OUT+** |
| **GND** | Газар | TP4056 **OUT−**, OLED **GND**, MPU9250 **GND**, C1 **−** |
| **3V3** | 3.3 V гаралт (ME6217 LDO, 800 мА) | OLED **VCC**, MPU9250 **VCC** |
| **GP6** | I2C SDA | OLED **SDA**, MPU9250 **SDA** |
| **GP7** | I2C SCL | OLED **SCL**, MPU9250 **SCL** |
| TX, RX, GP1–GP5, GP8–GP13 | — | Холбогдохгүй |
| Арын дэвсгэрүүд (GP14–18, 21, 38–45) | — | Холбогдохгүй (GP21 = самбар дээрх RGB LED) |

Firmware-ийн `PIN_SDA = 6`, `PIN_SCL = 7` тохиргоо хэвээрээ, өөрчлөх шаардлагагүй.

### OLED дэлгэц (J2): 4 хөл, бүгдийг ашиглана

| OLED хөл | Хаашаа холбогдох вэ |
|---|---|
| **GND** | S3-Zero **GND** |
| **VCC** | S3-Zero **3V3** |
| **SCL** | S3-Zero **GP7** |
| **SDA** | S3-Zero **GP6** |

PCB дээр OLED-ийн хөлүүд дээр байрлана (самбарын дээд ирмэг тал). Тиймээс `motioncare_c3.ino`-д дараах тохиргоог хийнэ:

```cpp
#define OLED_ROTATE_180  0
```

### MPU9250 (J3): 10 хөлөөс 4-ийг ашиглана

| MPU9250 хөл | Хаашаа холбогдох вэ |
|---|---|
| **VCC** | S3-Zero **3V3** |
| **GND** | S3-Zero **GND** |
| **SCL** | S3-Zero **GP7** |
| **SDA** | S3-Zero **GP6** |
| EDA, ECL, AD0, INT, NCS, FSYNC | Холбогдохгүй |

AD0-ийг одоогийн туршилтын холболттой адил холбохгүй үлдээнэ. Туршилтад MPU9250 0x68 хаягаар ажилласан тул өөрчлөх зүйлгүй.

### TP4056 цэнэглэгч (хамгаалалттай, USB-C): 4 дэвсгэр

| TP4056 дэвсгэр | Хаашаа холбогдох вэ |
|---|---|
| **B+** | LiPo батерейн улаан (+) утас |
| **B−** | LiPo батерейн хар (−) утас |
| **OUT+** | PCB-ийн **J1 «OUT+»** нүх, цааш **VBAT** шугам |
| **OUT−** | PCB-ийн **J1 «OUT−»** нүх, цааш **GND** шугам |
| USB-C | Батерей цэнэглэх кабель |

### D1: SS34 Шоттки диод (SMA, гадаргуун суурилуулалт)

| D1 хөл | Хаашаа холбогдох вэ |
|---|---|
| **A** (анод, судалгүй тал) | **VBAT**: TP4056 OUT+, C1 +, J4 VBAT |
| **K** (катод, **саарал судалтай тал**) | **VSYS**: S3-Zero **5V** |

PCB-ийн доод талын бичээс дээр давхар зураасаар тэмдэглэсэн «K» тал руу диодын судлыг харуулж наана.

### C1: 470 µF конденсатор (B самбар, хэвтээ)

| C1 хөл | Хаашаа холбогдох вэ |
|---|---|
| **+** (урт хөл) | **VBAT** (J4-ээр дамжиж TP4056 OUT+) |
| **−** (богино хөл, судалтай тал) | **GND** |

## 3. J4: хоёр самбарын хоорондох холбогч (5 хөл)

A самбарын доод талд эрэгтэй (pin header), B самбарын дээд талд эм (female header) холбогч суулгана. Дээрээс харахад зүүнээс баруун тийш:

| № | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| Шугам | **VBAT** | **SDA** | **3V3** | **GND** | **SCL** |
| x (мм) | 21.00 | 23.54 | 26.08 | 28.62 | 31.16 |

Хоёр самбар дээр J4 болон бэхэлгээний нүхнүүд яг ижил координаттай байгаа тул буруу залгах боломжгүй.

## 5. Угсрах дараалал

1. **D1**-ийг A самбарын доод талд гагнана. Судалтай (K) талыг «K» тэмдэг рүү харуулна.
2. **ESP32-S3-Zero**: модульд 2 × 9 pin header гагнана. Модулийг A самбарын **доод** талаас, бүрэлдэхүүн хэсгүүд нь доошоо харсан, USB-C нь самбарын доод ирмэг рүү харсан байдлаар оруулж, дээд талаас гагнана.
   - Хуванцар тусгаарлагч нь модуль ба PCB-ийн хооронд ≈ 2.5 мм зай үлдээнэ.
   - BOOT ба RESET товч хоёр самбарын хооронд үлдэнэ. Програм хуулахад ихэвчлэн шаардлагагүй.
3. **TP4056**-ийг A самбарын доод талд давхар туузаар наана. USB-C нь доод ирмэг рүү харна. OUT+ ба OUT− дэвсгэрийг J1-ийн нүхтэй богино утсаар холбоно. **OUT+ → «OUT+»**, **OUT− → «OUT−»**.
4. **OLED**-ийг A самбарын дээд талд суулгана. Хөлийн дараалал GND, VCC, SCL, SDA бөгөөд самбар дээрх бичээстэй таарч байгааг шалгаарай.
5. **J4 эрэгтэй** header-ийг A самбарын доод талд суулгана.
6. **B самбар**: дээд талд J4 эм header, доод талд MPU9250 болон C1-ийг (хэвтүүлж, «+» тэмдгийг харж) суулгана.
7. Хоёр самбарыг J4-өөр залгаж, M2 × 11 мм тулгуураар бэхэлнэ. Тулгуурын урт = эм header 8.5 мм + эрэгтэй header-ийн хуванцар 2.5 мм.
8. LiPo батерейг TP4056-ийн **B+ / B−**-д гагнана. Батарей B самбарын доор байрлана.

### Анхны асаалтын өмнө мультиметрээр шалгах

| Шалгах | Хүлээгдэх үр дүн |
|---|---|
| VBAT ↔ GND (батарейгүй) | Богино холболт **биш** (C1 цэнэглэгдэх үед утга аажмаар өснө) |
| 3V3 ↔ GND | Богино холболт **биш** |
| Батарей залгасны дараа J4 VBAT | 3.7–4.2 V |
| S3-Zero 5V хөл | VBAT-аас ≈ 0.3 V бага (D1-ийн уналт) |
| S3-Zero 3V3 хөл | 3.2–3.3 V |

## 6. Аюулгүй ажиллагаа

- **Батерейг 3V3 хөлд хэзээ ч бүү залга.** Батерей зөвхөн TP4056 → D1 → 5V замаар орно.
- **TP4056-ийн B− нь GND биш.** Хамгаалалтын хэлхээ B− ба OUT−-ийн хооронд байрладаг тул B−-г PCB-ийн GND-д бүү холбо.
- **D1-ийн чиглэл маш чухал.** Урвуу гагнавал батерейгаар асахгүй. Тэр үед S3-Zero-ийн USB-C-ийг залгавал 5 V диодоор дамжин батерей руу шууд орж, **аюултай**. Анх асаахаасаа өмнө 5-р хэсгийн хүснэгтээр заавал шалгаарай.
- Хоёр USB-C-ийг (TP4056 болон S3-Zero) нэгэн зэрэг залгаж болно. D1 тэдгээрийг тусгаарладаг.
- Батерейн хүчдэл ≈ 3.5 V-оос доош унахад D1-ийн уналт (≈ 0.3 V) ба LDO-ийн уналтын улмаас Wi-Fi дамжуулалтын үед 3V3 бууралт үүсч, ESP32 дахин ачаалагдаж болно. Ийм үед цэнэглэнэ үү.

## 9. Шалгалтын үр дүн

- **Хөлийн байрлал:** ESP32-S3-Zero-ийн хөлийн байрлалыг Waveshare-ийн албан ёсны хэмжээсийн зурагтай тулгаж программаар шалгасан:
  - модулийн хэмжээ 18.00 × 23.50 мм,
  - эгнээ ирмэгээс 1.38 мм, эхний хөл дээд ирмэгээс 1.59 мм,
  - алхам 2.54 мм, эгнээ хоорондын зай 15.24 мм.
- **Netlist:** Хоёр самбар хоёулаа дээрх хүснэгттэй 100 % таарч байна. Тасарсан болон илүү холболт алга.
- **DRC:** Зам, дэвсгэр, via хоорондын зай ≥ 0.3 мм, самбарын ирмэг болон нүхнээс ≥ 0.4 мм. TP4056-ийн доор доод давхаргын зэс байхгүй.
- **Gerber:** Бүх Gerber файл pygerber-ээр алдаагүй уншигдсан.
  - A самбар: 31 металлжуулсан нүх (29 хөл + 2 via).
  - B самбар: 18 металлжуулсан нүх (17 хөл + 1 via).
