# MotionCare v2 — Холболтын хүснэгт (ESP32-C3 SuperMini · MPU9250 · TP4056)

## Сүлжээ (net) бүрээр

| Сүлжээ | Хүчдэл / төрөл | Холбогдох цэгүүд | Дамжуулагч |
|---|---|---|---|
| BATP | Батерей «+» | J1 «+» (18650) → U2 **B+** | 80 mil |
| BATN | Батерей «−» | J1 «−» (18650) → U2 **B−** | 80 mil |
| VBAT | 3.7–4.2V тэжээл | U2 **OUT+** → C1 «+» (470µF) → U1 **5V** → BZ1 «+» | 80 mil |
| GND | Газардуулга | U2 **OUT−** → C1 «−» → U1 **GND** → J2 GND → J3 GND → Q1 E | 80 mil |
| 3V3 | 3.3V (U1-ийн LDO) | U1 **3V3** → J2 VCC (OLED) → J3 VCC, J3 NCS (MPU9250) | 80 mil |
| SDA | I2C өгөгдөл | U1 **GPIO6** → J2 SDA → J3 SDA | 60 mil |
| SCL | I2C цаг | U1 **GPIO7** → J2 SCL → J3 SCL | 60 mil |
| BUZ_B | Buzzer удирдлага | U1 **GPIO4** → R1 (1K) хөл 1 | 60 mil |
| BUZ_Q | Транзисторын суурь | R1 хөл 2 → Q1 **B** | 60 mil |
| BUZ_N | Buzzer «−» | BZ1 «−» → Q1 **C** | 60 mil |

Цэнэглэх: U2 (TP4056)-ийн USB-C порт — платын баруун ирмэг.

## Эд анги тус бүрээр

| Ref | Эд анги | Зүү → сүлжээ |
|---|---|---|
| U1 | ESP32-C3 SuperMini | 5V ← VBAT · GND · 3V3 → OLED/MPU · GPIO6 = SDA · GPIO7 = SCL · GPIO4 = Buzzer |
| U2 | TP4056 цэнэглэгч модуль (USB-C, хамгаалалттай) | OUT+ = VBAT · OUT− = GND · B+ = J1 «+» · B− = J1 «−» |
| J1 | Батерейн холбогч (2-pin) | «+» = 18650 «+» · «−» = 18650 «−» |
| C1 | 470µF электролит (≥10V) | «+» = VBAT · «−» = GND |
| J2 | OLED SSD1306 0.96" (4-pin) | GND · VCC = 3V3 · SCL = GPIO7 · SDA = GPIO6 |
| J3 | MPU9250 GY-9250 (10-pin) | VCC = 3V3 · GND · SCL = GPIO7 · SDA = GPIO6 · NCS = 3V3 (I2C горим) · EDA/ECL/AD0/INT/FSYNC холбогдохгүй |
| R1 | 1K резистор | GPIO4 ↔ Q1 B |
| Q1 | 2N2222 (TO-92, NPN) | C = Buzzer «−» · B = R1 · E = GND |
| BZ1 | Идэвхтэй buzzer | «+» = VBAT · «−» = Q1 C |

## Тэмдэглэл

- Ачааллыг заавал TP4056-ийн **OUT+/OUT−**-ээс авна (хамгаалалтын хэлхээ дамжина). B− ба OUT− нь өөр сүлжээ.
- U1-д тэжээлийг **5V зүүгээр** өгнө. **3V3 зүүнд шууд бүү холбо** — 4.2V нь ESP32-C3-ийг гэмтээнэ.
- MPU9250 I2C хаяг 0x68 (AD0 = 0), OLED 0x3C. Firmware: `Wire.begin(6, 7)`. Магнитометр (AK8963) 0x0C хаягаар bypass горимоор уншигдана.
- TP4056 модулийн pad-ын байрлал (OUT+, B+, B−, OUT− баганаар) загвараас хамаарч бага зэрэг өөр байж болно — модулиа тавиад тааруулж шалгаарай, шаардлагатай бол богино утсаар холбоно.
- 2N2222-ийн хөлийн дараалал үйлдвэрлэгчээс хамаарч өөр байж болно (EBC / CBE) — datasheet-ээ шалгаарай.
