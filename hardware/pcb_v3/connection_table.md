# MotionCare v3 — 2 давхар PCB, холболтын хүснэгт

Хэмжээ: **36 × 34 мм** (2 самбар ижил хэмжээтэй, давхарлана). Самбар бүр 2 давхаргатай → нийт 4 давхарга зэс.
Утасны өргөн: тэжээл (VBAT, GND, 3V3) **80 mil**, I2C **60 mil**. Зай ≥ 0.3 мм.

## Самбар хоорондын холбогч J4 (5 зүү, 2.54 мм)

| J4 зүү | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| Сүлжээ | SDA | SCL | GND | 3V3 | VBAT |

A-ийн доод талд эрэгтэй (male), B-ийн дээд талд эм (female, 8.5 мм) header. Хоёр самбар дээр ижил байрлалд (баруун доод).

## Самбар A — дэлгэцийн самбар

| Сүлжээ | Холбогдох цэгүүд |
|---|---|
| VBAT | J1 OUT+ (TP4056) → U1 **5V** → J4.5 |
| GND | J1 OUT− (TP4056) → U1 **GND** → J2 GND (OLED) → J4.3 |
| 3V3 | U1 **3V3** → J2 VCC (OLED) → J4.4 |
| SDA | U1 **GPIO6** → J2 SDA → J4.1 |
| SCL | U1 **GPIO7** → J2 SCL → J4.2 |

- Дээд тал: **J2 OLED** (толгой нь доод ирмэгт → дэлгэцийн дүрсийг firmware дээр 180° эргүүлнэ: `display.setRotation(2)`).
- Доод тал: **U1 ESP32-C3 SuperMini** (USB дээд ирмэгт), **TP4056 модуль** (наана, USB-C доод ирмэгт), **J1** (TP4056 OUT+/OUT− утас), **J4** (male).

## Самбар B — мэдрэгчийн самбар

| Сүлжээ | Холбогдох цэгүүд |
|---|---|
| VBAT | J4.5 → C1 «+» |
| GND | J4.3 → C1 «−» → J3 GND (MPU9250) |
| 3V3 | J4.4 → J3 VCC |
| SDA | J4.1 → J3 SDA |
| SCL | J4.2 → J3 SCL |

- Дээд тал: **J4** (female).
- Доод тал: **J3 MPU9250** (EDA, ECL, AD0, INT, NCS, FSYNC холбогдохгүй), **C1 470µF** (хэвтүүлж суулгана).

## Шалгалт (автомат)

- Хоёр самбарын холболт дээрх хүснэгттэй 100% таарсан, тасархай сүлжээ байхгүй.
- Өөр сүлжээний зэс хоорондын зай ≥ 0.3 мм, ирмэг ба нүхнээс зайтай. Gerber бүх файл алдаагүй уншигдана.
- Via: A самбарт 3, B самбарт 2.

## Угсрах дараалал ба анхааруулга

1. Доод талд суурилах модулийн (ESP32, MPU9250, TP4056) байрлалыг доод талын бичээстэй (silkscreen) тулгана — зүүний нэрс тэнд бичээстэй.
2. J4, OLED, MPU9250 зэрэг зүүний үзүүрийг эсрэг талд нь **тэгшлэн тайрна** (TP4056 болон ESP32 тэдгээрийн дээр байрлана).
3. TP4056-ийг **тусгаарлах давхар тууз**аар (foam tape) наана — доор нь зам гарсан.
4. Бугуйн цагт 18650 багтахгүй тул **хавтгай LiPo** (жишээ 503035, 3.7V ~500 mAh) хэрэглэнэ. TP4056 модуль анхдагчаар **1A**-аар цэнэглэдэг — 500 mAh-аас бага батерейд модулийн R_PROG (1.2kΩ)-ийг **2.4kΩ** (≈500 mA) эсвэл илүү болгож солих хэрэгтэй.
5. B− ба OUT− нэг цэг биш — батерейг зөвхөн TP4056-ийн B+/B−-д холбоно.
6. Firmware: `Wire.begin(6, 7)`; OLED 0x3C, MPU9250 0x68.
